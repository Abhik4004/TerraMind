# TerraMind

AI-powered geospatial land analysis. Ask about soil, weather, roads, flood risk
and construction suitability for any point on the map, in plain language.

Backend: FastAPI + LangGraph + ChromaDB + Ollama (in-container).
Frontend: React + Mapbox, served from the same container.
